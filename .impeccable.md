## Design Context
## BTV Olympia Dashboard
**Project Type**: Laravel + Statamic Application
**Domain**: Pickleball League Management System
**Tech Stack**: Tailwind CSS v4, Alpine.js, Antlers Templates

## Brand Personality & Aesthetic
- **Tone**: Very modern, clean, slick, young, and functional.
- **Vibe**: Professional sports tracking tool wrapped in a highly polished, "Linear/Vercel-esque" UI. 
- **Core Aesthetic**:
  - Focus on **clean lines**, smooth subtle interfaces, and premium feel.
  - **No AI-Slop**: Avoid excessive `backdrop-blur` and diffuse colored drop-shadows. Shadows should be crisp, realistic elevation shadows.
  - **Border Radii**: Use refined curves (`rounded-lg` or `rounded-xl`), completely avoiding extreme `rounded-[2.5rem]`.
  - **Color**: Minimalist palette. Use color functionally (e.g., subtle solid emeralds or indigos for active states) rather than washing the UI in gradients.

## Functional Requirements
- **Mobile-First Excellence**: The UI must be a charm to interact with on mobile. Good touch targets, crisp drawers.
- **Typography & Hierarchy**: Excellent typography. Use varied font weights purposefully (e.g., `font-medium` and `font-semibold` for readability), reserving `font-black` strictly for very select, prominent metrics or page titles. 
- **Micro-animations**: Small, snappy, and tactile transitions (e.g., translate, scale, and color shifts on hover) that feel responsive, not decorative.
- **High Contrast**: Ensure clear visual hierarchy without relying entirely on backgrounds. Use crisp borders (`border-gray-200` / `dark:border-gray-800`) to define structure.
3. **Structured & Solid**: Rely on strong borders, flat colors, distinct contrasts, and generous spacing instead of gradients and soft elements.
4. **Typographic Hierarchy**: Use font weights, tracking, and sizing intentionally to guide the user's eye without relying too heavily on color.
